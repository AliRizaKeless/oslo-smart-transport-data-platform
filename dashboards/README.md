Power BI Dashboards



This folder contains Power BI dashboards and analytics outputs for:

\- Oslo public transport departures

\- Weather conditions in Oslo

\- Transport analytics and KPI visualizations



Data Sources

The initial dashboard will use the following processed files:

\- `data/processed/oslo\\\_s\\\_departures.csv`

\- `data/processed/oslo\\\_weather.csv`

These files are generated by the Python ETL pipeline and can be loaded into Power BI.
